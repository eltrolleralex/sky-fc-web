Privacidad de las suscripciones

Responsable y finalidad

El responsable de las comunicaciones es el club M+Qpizza SKY FC, Albacete. Para consultas previas a la activación de las suscripciones puedes contactar con el club mediante su Instagram oficial. Antes de habilitar el registro por correo, el club publicará una dirección de contacto específica para el ejercicio de derechos.

Si decides suscribirte, se utilizará únicamente el correo que facilites para enviarte noticias, próximos partidos, resultados y comunicaciones del equipo. La base jurídica es tu consentimiento y el alta por correo exigirá confirmación mediante un segundo correo.

Proveedores y conservación

Las suscripciones por correo se tramitarán con Brevo cuando esté configurado. Las notificaciones push se gestionarán a través de OneSignal si el usuario las activa y su dispositivo lo permite. El canal de WhatsApp, una vez disponible, se gestiona mediante WhatsApp y sus condiciones de privacidad. Las plataformas pueden tratar identificadores técnicos necesarios para el servicio. Se conservarán los datos mientras mantengas la suscripción y durante el tiempo adicional legalmente exigible para acreditar consentimientos.

Cómo dejar de recibir avisos

En cada comunicación comercial por correo habrá un enlace para darse de baja. Puedes dejar de seguir el canal de WhatsApp desde la aplicación y desactivar las notificaciones push desde el navegador o el dispositivo. Puedes solicitar acceso, rectificación, supresión, oposición o limitación de tus datos al club. También puedes reclamar ante la Agencia Española de Protección de Datos.

Suscripción voluntaria

Los tres canales son independientes. No recibirás mensajes del club por el mero hecho de visitar esta página ni por rellenar un formulario aún no habilitado.
